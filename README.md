# LinkedIn Organic Content Strategy for B2B SaaS

## Objective
This project researches how successful B2B SaaS creators use LinkedIn and YouTube content strategies to build audience trust, improve engagement, and generate inbound opportunities.

## Technical Work
Implemented transcript extraction using the YouTube Transcript API.

The workflow included:
1. Selecting YouTube videos from relevant creators
2. Extracting video transcripts using Python
3. Organizing raw and processed research files
4. Creating structured markdown research documents

---

## What I Collected
- LinkedIn posts organized by creator
- YouTube video transcripts
- Hook analysis and content framework notes
- Posting pattern observations
- Research summaries and strategy insights

---

## Key Learnings
- Strong hooks improve engagement and retention
- Educational content builds audience trust
- Consistency is critical for organic growth
- B2B SaaS creators rely heavily on audience positioning and clarity
- Content can support both lead nurture and demand generation

## Issues Faced

### 1. Cursor Authentication Issue
Problem:
Cursor failed to verify the account during signup.

Solution:
Switched from the desktop application to browser authentication and then logged back into the app.

### 2. Transcript Collection Challenges
Problem:
Some videos had unavailable or inconsistent transcript formatting.

Solution:
Selected videos with accessible transcripts and cleaned transcript formatting before organizing the files.

### 3. Organizing Large Research Data
Problem:
Managing multiple creators, posts, and transcripts became difficult.

Solution:
Created a structured folder system separated by creator and content type.
